## 📌 Project Description
This project is a web-based recruitment system that connects candidates and employers using a two-way intelligent recommendation system.

## 🚀 Features
- Candidate profile creation
- Job posting system
- Search and filtering
- Recommendation system
- Membership-based access

## 🛠 Tech Stack
Frontend: React  
Backend: Node.js + Express  
Database: MongoDB / MySQL  

## 📂 Project Structure
- frontend → UI
- backend → server logic
- docs → reports & diagrams
